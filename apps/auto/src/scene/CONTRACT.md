# Контракт модели `auto.glb`

Модель машины для сцены «Автосервис»: кузов, салон, колеса и 8 узлов «где болит». Модель собирается скриптами
Blender 5.2 с нуля в репозитории дизайна студии, руками не правится; в демо попадает готовый файл. Код сцены
(`src/scene/`) и объяснялок двигает только части из таблицы «Движущиеся части», все остальное статично.

## Файл

- `public/scene/auto.glb`, не больше 3 МБ (3 000 000 байт).
- Обязательные расширения: `EXT_meshopt_compression`, `KHR_mesh_quantization`, `KHR_texture_basisu` — загрузчику
  нужны `MeshoptDecoder` и `KTX2Loader`. Также используются `KHR_materials_clearcoat`, `KHR_materials_transmission`,
  `KHR_materials_emissive_strength`.
- Текстуры — KTX2 (карты нормалей — UASTC 512 px, шероховатость — ETC1S 1024 px), Poly Haven, CC0.
- Затенение узлов: у каждого материала сеток узлов — `occlusionTexture` (`node-ao`, ETC1S 1024 px) по второй
  развертке `TEXCOORD_1`. Карта запечена между деталями узлов, без кузова: в сфере сканера кузов вырезан. Кузовные
  сетки с материалами, общими с узлами (`chrome`, `plastic_black`, `signal_amber`), смотрят в белый угол карты —
  затенения у них нет.
- Единицы — метры. Оси glTF: **+X — вперед** по ходу машины, **+Y — вверх**, **+Z — вправо** (к правому борту).
  Начало координат — на земле под серединой колесной базы, колеса стоят на y = 0.

## Иерархия

```
car
├─ body        панели кузова: капот, двери, крылья, бамперы, крыша, стекла, днище
├─ front       фары, решетка, заборники, защита бампера
├─ rear        фонари, полоса на двери багажника, защита
├─ trim        расширители арок, накладки, зеркала, ручки, рейлинги, спойлер, дворники
├─ interior    салон силуэтами
├─ wheels      wheel_fl, wheel_fr, wheel_rl, wheel_rr — в каждом tire_* и rim_*
└─ nodes       восемь узлов: node_<id>
```

## Узлы

| Корень              | id             | Что внутри                                                                              |
| ------------------- | -------------- | --------------------------------------------------------------------------------------- |
| `node_engine`       | `engine`       | двигатель, открытый привод ГРМ (цепь, звездочки, успокоители, натяжитель), впуск, опоры |
| `node_suspension`   | `suspension`   | стойки, пружины, амортизаторы, рычаги, стабилизатор, подрамники                         |
| `node_brakes`       | `brakes`       | диски, суппорты, вакуумный усилитель, главный цилиндр, тормозные трубки                 |
| `node_steering`     | `steering`     | руль, колонка, карданы, рейка, тяги                                                     |
| `node_electrics`    | `electrics`    | АКБ (с пластинами внутри), провода, генератор, стартер                                  |
| `node_cooling`      | `cooling`      | радиатор, вентилятор, патрубки, расширительный бачок                                    |
| `node_exhaust`      | `exhaust`      | коллектор, турбина, катализатор, глушители                                              |
| `node_transmission` | `transmission` | сцепление в колоколе, коробка, приводы, кардан, задний редуктор                         |

- `id` совпадают с `NODE_KEYS` в `src/consts.ts` и `NODE_SPECS` в `src/scene/nodes.ts`. Выбор узла кликом: от сетки, в которую попал луч, подниматься по родителям
  до узла с именем `node_*`; `id` — имя без префикса.
- Статичные детали узла — по одной сетке на материал: `<id>_<материал>` (например, `engine_cast_iron`). Материалы
  узлов: `cast_iron`, `aluminum`, `steel` (карты металла), `rubber_parts` (карты резины), `painted_black`, `zinc`
  (крепеж), `exhaust_steel`, `caliper`, `friction`, `lead`, `battery_case`, `cable_red`, `tank_white`, `chrome`,
  `plastic_black`, `signal_amber`.
- Тормозные диски — в `node_brakes`, с колесами не вращаются (диски осесимметричны, вращение не видно).

## Движущиеся части

Каждая движущаяся часть — пустой узел-опора с именем из таблицы, внутри него сетки `<имя>_<материал>`. Код меняет
только опору. Узлы сеток не трогать: в их трансформе — поправка квантования сжатых вершин.

| Имя                              | Узел              | Опора                                                                           | Движение                                                                                                                                                         |
| -------------------------------- | ----------------- | ------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `sprocket_crank`                 | `node_engine`     | центр звездочки коленвала: 19 зубьев, шаг цепи 12,7 мм, радиус по шагу 0,0386 м | поворот вокруг локальной **Y**; локальная Y смотрит влево (−Z мира)                                                                                              |
| `sprocket_cam`                   | `node_engine`     | центр звездочки распредвала: 38 зубьев, радиус по шагу 0,0769 м                 | поворот вокруг локальной **Y**, та же ось; без растяжения угол распредвала = угол коленвала / 2; растяжение цепи — добавочный поворот этой звездочки (сдвиг фаз) |
| `chain`                          | `node_engine`     | —                                                                               | одна сетка, не двигается: растяжение показывают поворотом `sprocket_cam` и подписью                                                                              |
| `spring_fl`, `spring_fr`         | `node_suspension` | нижняя чашка пружины                                                            | масштаб по локальной **Y**: `scale.y = (0.225 − ход) / 0.225`; ось — вдоль стойки (вверх, с наклоном внутрь)                                                     |
| `spring_rl`, `spring_rr`         | `node_suspension` | нижняя чашка на рычаге                                                          | масштаб по локальной **Y**: `scale.y = (0.165 − ход) / 0.165`; ось вертикальна; верхняя чашка и подушка внутри опоры — едут с верхом пружины                     |
| `damper_rod_fl`, `damper_rod_fr` | `node_suspension` | вход штока в корпус амортизатора                                                | перенос вдоль локальной **Y** на `−ход`; с штоком едут верхняя чашка пружины и опора стойки; видимая длина штока 0,224 м                                         |
| `damper_rod_rl`, `damper_rod_rr` | `node_suspension` | вход штока в корпус                                                             | перенос вдоль локальной **Y** на `−ход`; с штоком едет верхняя опора; видимая длина 0,169 м                                                                      |
| `wheel_fl`, `wheel_rl`           | `wheels`          | центр колеса                                                                    | поворот вокруг локальной **Z**; при движении вперед угол убывает                                                                                                 |
| `wheel_fr`, `wheel_rr`           | `wheels`          | центр колеса                                                                    | поворот вокруг локальной **Z**; при движении вперед угол растет                                                                                                  |

- **Ход подвески** — сближение кузова и колеса, метры: плюс — сжатие, минус — отбой. Допустимо ±0,08 м: шток
  заходит в корпус на 0,08 м с запасом, щели не будет. Колесо, кулак, корпус амортизатора и нижняя чашка
  стоят: модель показывает движение кузова относительно колеса. Колеса двигать только вращением.
- Обозначения колес: `fl` — переднее левое, `fr` — переднее правое, `rl` и `rr` — задние. Левый борт — −Z.

## Плотности «Снимка»

У каждой сетки — `extras.xray_k`: плотность слоя для вида «Снимок» и «Сканер». Слой пропускает
`T = exp(−k·w / max(|n·v|, 0.05))` и светится `a = 1 − T` (экранное смешение, без bloom), `n·v` — косинус угла к лучу
(ограничение 0,05 — чтобы кромка не уходила в бесконечную толщину), `w` — веса каналов пленки `(0.70, 0.85, 1.00)`.

- `k` сетки — `k` материала, который покрывает больше всего ее граней (панель кузова — краска с черной вставкой).
  Таблица материалов — `XRAY_K` сборки модели, без значения по умолчанию: новый материал без плотности ломает
  сборку.
- Сводка порядка (точные числа — только `XRAY_K`): ткань, стекло, линзы (0,006–0,02) < бачок, сетки, пластик,
  краска (0,03–0,06) < резина, корпус АКБ, провода, выхлоп (0,08–0,12) < диски, ламели, фрикцион, алюминий, суппорты
  (0,18–0,3) < чугун, черненая сталь, свинец, сталь, хром (0,35–0,5) < крепеж `zinc` (2,0). Крепеж, пружины и цепь
  светлее панелей.
- Рендеры постеров (вид Standard) умножают `k` на 0,35: ×1 пережигает двигатель в белое. Множитель — дело рендера
  или сцены (`K_SCALE` в `src/scene/stage.ts`), в GLB его нет.

## Бокс

Бокс сервиса вокруг машины — отдельный файл `public/scene/env.glb`, не больше 2 МБ (2 000 000 байт), те же оси
и начало координат, что у машины. Расширения: `EXT_meshopt_compression`, `KHR_mesh_quantization`,
`KHR_texture_basisu`; `KHR_materials_emissive_strength` — у рассеивателей ламп (`env_glow`). Статичный бокс не освещается в реальном времени: свет ламп, тени и отскоки запечены в карту
излучения (`emissiveTexture`, ETC1S 1024 px) по своей развертке, цвет материала черный. Пол сверх того отражает:
шероховатость и рельеф `garage_floor` по первой развертке.

| Имя         | Что внутри                                                                                                  | Движение                                     |
| ----------- | ----------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| `env`       | корень бокса                                                                                                | —                                            |
| `env_floor` | бетонный пол: две развертки — повтор карт и запеченный свет                                                 | —                                            |
| `env_room`  | стены, ворота, разметка, стойки подъемника, стеллажи, верстак, тележки, корпуса ламп — одна сетка           | —                                            |
| `env_glow`  | рассеиватели ламп: излучение без запекания                                                                  | —                                            |
| `lift_arm`  | опора подвижной части подъемника: каретки, лапы, упоры (`lift_arm_paint`, `lift_arm_steel`, `lift_arm_pad`) | перенос вдоль **Y** на 0…`extras.lift_max` м |

- `lift_arm` стоит на полу между стойками (x = −0,25). В покое верх упоров = низ порогов машины (0,326 м): машина
  стоит колесами на полу. Подъем — перенос опоры вдоль Y; машина едет вместе с ней: y машины = y опоры.
- Материалы `lift_arm` — обычный PBR (освещение — окружение): подвижную часть запеченный свет не описывает.
- Стены — плоскости лицом внутрь, без двусторонней отрисовки: камера снаружи видит бокс сквозь стену.
- Надписей, шильдиков и логотипов на стеллажах, ящиках и инструменте нет.

## Проверка

Проверка сборки модели (в репозитории дизайна): размер, имена из этого файла (каждое ровно один раз), восемь корней
узлов с сетками, Meshopt и числовой `extras.xray_k` у всех сеток, KTX2 не больше 1024 px, нет пустых сеток,
затенение узлов. Проверка бокса: размер, имена таблицы «Бокс» ровно по одному, `extras.lift_max` у `lift_arm`, две
развертки пола (карты — по первой, свет — по второй), Meshopt, KTX2 не больше 1024 px. Сцена демо проверяет при
загрузке то, без чего не работает: `extras.xray_k` у сеток, корни `node_*` из списка узлов, опоры колес и звездочек,
`lift_arm` с `extras.lift_max`.
